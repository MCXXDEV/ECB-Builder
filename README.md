# ECB Builder

**ECB Builder** is a Minecraft Java **Fabric 1.21.1** mod that lets players generate original structures using simple `/ecb` commands. Instead of building every block by hand or using complicated vanilla command syntax, players can type a prompt like `/ecb build a house`, `/ecb build a city`, `/ecb build a castle`, or `/ecb build an underground bunker`, and ECB Builder will generate a Minecraft structure directly in the world.

ECB Builder is designed to be more than a basic house generator. It is a prompt-driven structure builder that can create many different types of builds, including houses, cities, castles, towers, bridges, farms, greenhouses, parks, statues, ships, docks, markets, libraries, temples, windmills, train stations, underground bases, cave builds, animal sculptures, dream builds, and more.

The mod uses a smart command system built around `/ecb`. Players can build instantly, preview a structure before placing it, confirm the preview, undo builds, save builds, paste saved builds, replace block palettes, add lighting, add animals, add mobs, and generate safe survival-friendly details.

## Main Features

* Simple `/ecb` command system
* Prompt-based structure generation
* Houses, cities, castles, towers, bridges, farms, statues, ships, underground bases, and more
* City generation with roads, buildings, parks, plazas, and lights
* Safe city limits to help prevent lag
* Terrain blending for hills, slopes, cliffs, and uneven ground
* Biome-adaptive palettes that match the surrounding biome
* Multi-color build support
* Underground and cave build logic
* Safe furniture and interior generation
* Preview and confirm system
* Undo and undo history
* Saved builds
* Blueprint-style import and export support
* Palette replacement tools
* Automatic lighting pass
* Context animals, mobs, and balanced loot support
* Server-friendly generation limits
* Survival-friendly safety rules

## Smarter Building

ECB Builder tries to make structures look clean, readable, and useful. Builds can include foundations, paths, lighting, framing, support pillars, roofs, windows, doors, interiors, landscaping, vegetation, and decorative details. The goal is to make generated structures feel more planned and less random.

For example, city prompts can generate multiple buildings, roads, lights, and public areas instead of only one house. Animal and statue prompts try to create sculpture-style builds with recognizable shapes. Underground prompts can generate bunker-style or cave-style structures with hollowed rooms, supports, lights, and safe work areas.

## Biome and Terrain Support

ECB Builder can adapt builds to the world around the player. If no color or style is specified, the mod can use biome-adaptive palettes. For example, desert builds may use sandstone-style blocks, taiga builds may use spruce-style blocks, badlands builds may use terracotta-style blocks, and mountain builds may use more stone-style materials.

The terrain blending system helps structures fit better on uneven ground. Instead of floating awkwardly or clipping into hills, builds can use deeper foundations, support pillars, or adjusted placement to look more natural in the world.

## Safe Survival-Friendly Design

ECB Builder is made to be useful without breaking survival gameplay. The mod avoids generating overpowered rewards, rare loot, diamonds, netherite, enchanted gear, or progression-breaking items. Loot and interior items are meant to stay balanced and low-level.

The mod is also designed to avoid unsafe, inappropriate, copyrighted, or trademarked builds. ECB Builder focuses on original Minecraft-style structures instead of copying real brands, copyrighted buildings, or protected franchise designs.

## Build Quality Notice

ECB Builder is a procedural structure generation mod, so every build is created based on the prompt, terrain, biome, and available generation logic. While the mod tries to create clean, useful, and good-looking structures, it does **not guarantee** that every house, city, castle, statue, or custom build will look perfect or match every player’s personal style.

Some builds may need player edits, decoration, cleanup, or rebuilding to fully match what you want. ECB Builder is designed to help generate ideas, starter structures, layouts, and creative builds faster, but final appearance may vary depending on the prompt and world location.

## Who Is This Mod For?

ECB Builder is useful for survival players, creative builders, server owners, map makers, and anyone who wants faster structure creation. It can help players build starter bases, decorate worlds, generate towns, test ideas, create landmarks, or quickly fill empty areas with original builds.

## Installation

ECB Builder is made for:

* Minecraft Java Edition 1.21.1
* Fabric Loader
* Fabric API
* Java 21

For singleplayer, install the mod normally in your `mods` folder. For multiplayer servers, the mod should be installed on the server. Since ECB Builder mainly uses commands and vanilla blocks, it is mostly server-side/world-side unless future versions add custom blocks, items, textures, GUIs, or entities.

## Summary

ECB Builder is a powerful command-based Minecraft building mod that turns simple `/ecb` prompts into original structures. It supports houses, cities, castles, underground builds, animals, statues, dream builds, terrain blending, biome palettes, interiors, lighting, saved builds, undo tools, and safe survival-friendly generation. It is built to make Minecraft building faster, easier, cleaner, and more creative.
