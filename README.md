ECB Builder

ECB Builder is a Minecraft Java Fabric 1.21.1 mod that lets players generate original Minecraft structures using simple "/ecb" commands. Instead of placing every block by hand, players can type prompts like "/ecb build a house", "/ecb build a city", "/ecb build an underground base", or "/ecb build an underground city", and ECB Builder will generate the structure directly in the world.

ECB Builder is designed to help players build faster while still keeping the game survival-friendly, original, and editable. The mod can create houses, towns, cities, castles, towers, bridges, farms, greenhouses, parks, statues, docks, fountains, underground bases, underground cities, cave builds, storage rooms, and more.

EPC Buildet API

ECB Builder also supports the optional EPC Buildet API companion mod.

EPC Buildet API acts like a local planning brain for ECB Builder. It helps the main mod understand prompts, plan layouts, create Build IDs, improve underground structures, handle city planning, add safer access paths, improve furniture placement, and apply safety rules before the structure is built.

ECB Builder can run without the API, but the API is recommended for smarter underground bases, underground cities, city layouts, ladder access, lighting plans, mob clearing support, and safer structure placement.

Main Features

- Simple "/ecb" command system
- Prompt-based structure generation
- Houses, towns, cities, castles, underground bases, and underground cities
- Preview and confirm system
- Undo support
- Saved build support
- Terrain blending for hills, slopes, and uneven ground
- Biome-adaptive block palettes
- Better foundations for towns and cities
- Underground access tunnels, doors, ladders, and lighting
- Safer furniture placement so doors and beds are not blocked
- Dense underground lighting to reduce hostile mob spawning
- Hostile mob clearing support for underground structures
- Sorted storage support
- Balanced survival-friendly loot
- Optional EPC Buildet API planning support

Recommended Setup

For the best experience, install both:

ecb-builder.jar
epc-buildet-api.jar

ECB Builder is the main mod that places structures in the world.
EPC Buildet API is the optional companion brain that improves planning and generation logic.

Requirements

- Minecraft Java Edition 1.21.1
- Fabric Loader
- Fabric API
- Java 21

Survival-Friendly Design

ECB Builder is made to help players build faster without breaking survival gameplay. The mod avoids overpowered rewards, rare loot, diamonds, netherite, enchanted gear, and progression-breaking items.

The mod also focuses on original Minecraft-style structures instead of copying copyrighted or trademarked designs.

Build Quality Notice

ECB Builder uses procedural structure generation. Some builds may still need small player edits, decoration, cleanup, or improvement depending on the prompt, terrain, biome, and world location.
